# Opero Ajo

Tämä repo on Opero Ajon virallinen julkaisurepo.

## Virallinen tuotantotiedosto

- `index.html` = käytössä oleva Opero Ajo -sovellus

## Työskentelysääntö

Kun Codexia tai muuta työkalua käytetään Ajon korjauksiin, avaa aina:

- repo: `Hekse/index.html`
- branch: `main`
- tiedosto: `index.html`

Älä käytä `kontakti-mobile`-repon tiedostoja Ajon muokkauksiin. Ne kuuluvat Kontakti Mobiiliin.

## Huomio

Vanhoja testiversioita ja kehityskopioita ei pidetä tämän repon lähteenä. `index.html` on source of truth eli virallinen totuustiedosto.
