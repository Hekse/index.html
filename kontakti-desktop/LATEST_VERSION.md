# Kontakti Desktop – viimeisin tunnettu versio

Päivitetty: 2026-05-10

## Oikea viimeisin versio

Käyttäjän lataama tiedosto:

`kontakti_mvp_v1_1_google_calendar.html`

Tämä on uudempi kuin Gmailista löytynyt `Fwd: Kontakti` -versio.

## Versiotunnisteet

- Nimi: Kontakti MVP v1.1
- Mukana: Google Calendar -lisäys
- HTML-title: `Kontakti`
- Tallennus: IndexedDB
- Tuotemalli: `kontakti-desktop-mvp`
- Data schema version: `2`
- Integraatiovalmis rakenne: `KontaktiIntegration`
- Google Calendar -toiminto: `googleCalendarUrl(c)`
- Opero splash mukana
- FI/EN-kieliliput mukana
- Ajoa ei saa yliajaa tällä tiedostolla

## GitHub-polku tälle versiolle

Suositeltu lopullinen polku:

`kontakti-desktop/index.html`

## Huomio

Tätä tiedostoa ei saa sekoittaa repon juuressa olevaan `index.html`-tiedostoon, koska se on Opero Ajo.

Oikea jatkotoimi on tallentaa käyttäjän lataama `kontakti_mvp_v1_1_google_calendar.html` sisältönä polkuun:

`kontakti-desktop/index.html`

Tämän README:n tarkoitus on lukita, että sähköpostista löydetty versio ei ole enää pääversio, vaan käyttäjän lataama MVP v1.1 Google Calendar -versio on uusin tunnettu Kontakti Desktop -pohja.
